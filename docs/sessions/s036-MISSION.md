## Open questions
- (ui, 4.14/4.16, non-blocking) 4.16 renders `GoldfishChips` only when `design.goldfish` is not empty, but the cap line of 4.14 matters most when the session has no Goldfish yet (a skill start waits). Built variant: the block renders when `goldfish` is not empty or `goldfish_live >= GOLDFISH_LIVE_MAX`.
- (ui, 4.17, non-blocking) "Each step's tooltip ends with `Goldfish: $<cost_by_stage value>`": Approve has no `cost_by_stage` key (T6 keys are brainstorm, draft, review, build). Built variant: the four keyed steps end with `Goldfish: $x` (`$0.00` before any cost); Approve has no cost tail.
- (engine, 4.4, non-blocking) pi-subagents 0.84.0 runs an async fan-out as one `mode: workflow` run whose steps name a child run (`steps[].runId`), and each child writes its own run directory with the same `sessionFile`. Read as written, every Goldfish would show twice and cost twice (run F: 21 directories, 3 of them workflow roots). Built variant: a step whose `runId` names another run read is dropped from its workflow run; the chip key is the child's `<runId>/0`. `GoldfishStep` gains `index` and `child_run`, `GoldfishRun` gains `foreground`.
- (engine, 4.4, session 1 finding 4) foreground Goldfish: built as runs read from `agents/lead/pi/subagent-artifacts/<runId>_<agent>_<i>_transcript.jsonl` whose run has no async directory; `meta.json` present gives done or failed (exitCode), absent gives running, or stopped while the lead is not busy. The child's pi session is `<lead pi>/<lead session>/<runId>/run-<i>/session.jsonl`; that path is the cost and events source.
- (ui-workspace, 5.9, non-blocking) No route lists the files of an archived review run, so the Review tab cannot say which reports an archived run has. Built variant: an archived run lists all 7 rows marked `archived`; a report the run lacks shows the route's 404 text in the body.
- (ui-workspace, 5.8, non-blocking) `request revision` under each `## ` section needs the doc cut into sections. Built variant: the doc renders section by section (cut at `## ` outside code fences, all inside one `.md` root); a reference-style link whose definition sits in another section does not resolve.
- (ui-workspace, 5.11, non-blocking) `onStep` is wired, but `DesignStepper` (session 4's file) has no click in its folded form, and a design-track session folds at 1500 px since the build-session-3 toolbar. So at a normal window width the steps do not open the workspace; the driver clicks them at 1920 px. Proposal for ui-goldfish or a later session: make the folded `EGM 3/5 Review` label call `onStep` with the current step.
