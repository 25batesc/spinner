Dates are local-zone days, both inclusive; `to` defaults to today, `from` to 29 days before `to`; more than 366 days or `from > to` → 400; `group` defaults to `day`. `period` is `YYYY-MM-DD` (day), the Monday's `YYYY-MM-DD` (week), `YYYY-MM` (month). `by_period` lists only periods with a row, oldest first; `by_session`/`by_model`/`by_agent` by `usd` descending; the operator agent appears as `dir: "operator"`, title `Operator agent`.
  - **Event** `costs { type: "costs", ts, session: null, today: CostTotals, week: CostTotals, month: CostTotals, changed: { [dir]: SessionCost } }`, once per refold that changed a total; `today`/`week`/`month` are local-zone, the week from Monday. A changed session also gets a `session.updated`. `EVENT_TYPES` gains `costs`.
