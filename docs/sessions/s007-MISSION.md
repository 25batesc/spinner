# s007 · Desktop: the same UI in a window, previews as top-level pages

## Goal
M4. An Electron app that shows the existing web UI and renders each preview as a `WebContentsView`, a top-level page in its own right, so an app that keeps its session in `SameSite=Lax` cookies stays logged in inside Spinner. The app connects to a running daemon and starts one when none runs. The web UI in a browser keeps working unchanged. Two agents: `desktop` (the Electron package) and `ui` (the preview bridge in the web app).

- 11:50 desktop: **Bridge contract.** The type file is `packages/protocol/src/desktop-bridge.ts`, exported from `@spinner/protocol` (ui must not depend on the desktop package, which pulls Electron). Nothing in it is runtime; types and two constants only.
    ```ts
    /** The desktop shell puts this on `window` from the preload. Absent in a browser. */
    declare global { interface Window { spinnerDesktop?: SpinnerDesktop } }
    export const DESKTOP_BRIDGE_NAME = "spinnerDesktop";
    export interface SpinnerDesktop { previews: DesktopPreviews; daemon: DesktopDaemon }
    /** `<session dir>/<service name>`, for example `s006-refunds/admin`. One view per key. */
    export type PreviewKey = string;
    export function preview_key(session_dir: string, service: string): PreviewKey;
    /** CSS pixels relative to the page viewport, as `getBoundingClientRect()` gives them. Zoom 1. */
    export interface PreviewRect { x: number; y: number; width: number; height: number }
    export interface DesktopPreviews {
        /** Create the view on demand, load `url` when it differs from the last `set`, set bounds, show. */
        set(key: PreviewKey, url: string, rect: PreviewRect): Promise<void>;
        show(key: PreviewKey): Promise<void>;
        /** Keeps the page alive (its state survives); call on unmount and on tab switch. */
        hide(key: PreviewKey): Promise<void>;
        reload(key: PreviewKey): Promise<void>;
        /** The view's current URL in the default browser. */
        openExternal(key: PreviewKey): Promise<void>;
        devtools(key: PreviewKey): Promise<void>;
        /** Main → renderer: load state of a view. Returns the unsubscribe function. */
        subscribe(listener: (event: PreviewEvent) => void): () => void;
    }
    export type PreviewEvent =
        | { key: PreviewKey; type: "loading"; url: string }
        | { key: PreviewKey; type: "ready"; url: string; title: string }
        | { key: PreviewKey; type: "failed"; url: string; error: string };
    export interface DesktopDaemon {
        status(): Promise<DaemonStatus>;
        subscribe(listener: (status: DaemonStatus) => void): () => void;
    }
    export interface DaemonStatus { url: string; state: "connected" | "starting" | "down"; build: BuildInfo | null }
    ```
    Rules. (1) `set` on an existing key with the same `url` only moves the view; a changed `url` loads it. So the reload button must call `reload(key)`, not remount `Preview`: ui owns how `PreviewPane` passes that down. (2) The main process hides every view whose key is not the last `set` key, so only one preview shows at a time; `hide` is still the renderer's duty on unmount, so the "No session" text is not covered. (3) The main process destroys the views of a session on the daemon's `session.closed` event; the renderer never destroys. (4) A view that fails to load renders the error inside the view; the `failed` event is informational. (5) The rectangle must be sent on every `ResizeObserver` callback, on scroll, and on window `resize`; the main process does not poll. (6) Everything in the renderer runs through `contextBridge`; no Electron API is reachable from the page.
